# Phase 3: Segmentation model (training → ONNX → OpenCV 5)

**Goal:** a pothole segmentation model trained on AWS and running inside OpenCV 5's new DNN engine, giving end-to-end area MAPE ≤ 20%.
**Midpoint track:** yes.

## Checklist
**Deviation:** training ran on **AWS Batch, Graviton Spot, CPU only** (D-25), not SageMaker GPU. Details: [07-MODEL-CARD](../../midpoint/07-MODEL-CARD.md).

- [x] `training/prepare.py`: Pothole Mix v2 (real, D-24) + synthetic road-strip frames from `seed07` (held out by road stretch) + look-alike hard negatives (data v3); one `damage` class, cracks ignored. Augmentations in `train.py`: scale, damage-biased crop, flip, exposure, contrast, colour cast, blur, noise, JPEG
- [x] `training/train.py`: HF `SegformerForSemanticSegmentation` (`nvidia/mit-b0`), AdamW, poly LR, CE + soft Dice; logs IoU real vs synthetic; checkpoints to S3 every epoch, resumes after Spot interruptions
- [~] Licence-clean fallback `--arch lraspp` (LR-ASPP MobileNetV3, D-07): implemented, **not trained yet**
- [x] Launcher: `scripts/aws/submit_train.py` → Batch job definition `patchwork-train-cpu` (32 vCPU, 60 GB, Spot), tags `Project=patchwork`
- [x] Small plumbing run (`models/dev-plumbing`) and a first model `seg-v1` before the full `seg-v2` run; `seg-v3` fine-tunes `seg-v2`
- [x] ONNX export inside `train.py`: opset 17, dynamic H/W, **logits only** (resize + argmax in OpenCV)
- [x] `training/parity.py`: OpenCV `ENGINE_NEW` vs onnxruntime, max |Δ| 2.0e-5, 100% same pixel decisions; `ENGINE_CLASSIC` cannot load the model
- [x] `perception/segment.py`: blobFromImage, forward, upsample, argmax, morphology; 381 ms (OpenCV) vs 396 ms (onnxruntime) per strip on 4 vCPU
- [x] Severity v1 rules (`schema/models.py: severity_v1`) · [ ] v2 calibrated (second half)
- [x] Model registry: `s3://…-artifacts/models/<version>/` with `model.onnx`, `metrics.json`, `class_map.json`, `parity.json`, `eval_opencv.json`, checkpoints. The model card is [07-MODEL-CARD](../../midpoint/07-MODEL-CARD.md) (generated by `training/model_card.py`)
- [x] Visuals: `docs/midpoint/assets/seg_examples.jpg` (good and failure cases), `hard_neg_compare.jpg` (seg-v2 vs seg-v3 on look-alikes)

## Result (seg-v3, see [04](../../midpoint/04-RESULTS-AND-OUTPUTS.md))
Parity ✅ · end-to-end recall 0.94 ✅ · control-section false positives 0.30/km ✅ · IoU 0.50 real / 0.57 synthetic (below the 0.55 / 0.75 aim) ❌ · end-to-end area MAPE 27.8% (target ≤ 20%) ❌. Both misses are in the second-half plan ([06](../../midpoint/06-NEXT-STEPS.md)).

## Exit criteria
| Check | Target |
|---|---|
| ONNX parity (ENGINE_NEW vs onnxruntime) | max \|Δ\| ≤ 1e-3 |
| mIoU pothole: real val / synthetic val | reported (aim ≥ 0.55 / ≥ 0.75) |
| End-to-end area MAPE on D1 | ≤ 20% |
| Recall @ ≤ 1 FP/km on D1 | ≥ 0.85 |
| FP/km on D2 | ≤ 0.5 |
| Training cost of this phase | recorded in the cost report ($1.70 seg-v2 + ≈ $1.20 seg-v3, Batch Spot) |
