Patchwork: agent workflow (perception → decision & orchestration → action → verification)

The agent never sees pixels or invents numbers: it acts on what OpenCV 5 measured, through tools that only accept IDs that exist, and nothing is filed without a named human.
1 · PERCEPTION (OpenCV 5, AWS Batch)
Dashcam framestriage (Laplacian, LK optical flow) · privacy blur (YuNet)
SegmentationSegFormer-B2 in dnn ENGINE_NEW → damage mask
Bird's-eye measurementhomography + remap → area m² ± σ, length, width
Localisationroad chainage, lateral offset, GPS
Defect register (Aurora PostGIS)one row per defect: area, severity, status, evidence image
ObservabilityEMF metrics: km, defects, stage seconds
2 · DECISION & ORCHESTRATION (Nova on AgentCore)
query_defects · lookup_context · check_existing_ticketsreads measured areas and nearby schools, hospitals, bus stops; skips defects already ordered
cluster_into_packagesdeterministic exposure score from measured area, severity, road type, context → priority 1–3 + next step
estimate_materials · draft_work_orderhot-mix = area × thickness × density; every number from the database
request_human_approval · schedule_reinspectionlow confidence → options + re-inspection
Guardstools reject unknown IDs · DB trigger · answer checked for unknown IDs · no filing tool · token hidden from the model
Observabilityfull trace per run (S3) · AgentRuns, ToolCalls, UngroundedIds metrics
3 · ACTION (human control)
Step Functions approvalwaits on a task token (7-day timeout)
Approval consoleCognito sign-in; engineer reviews defects, materials, work order
Approve→ mock ticket filed
Reject→ override recorded (override rate on the dashboard)
Re-inspectionqueued for the next drive
4 · VERIFICATION (next drive)
Perception againsame OpenCV 5 pipeline on drive 2
Matcher v2 + pass closinglinked → unchanged / degraded; driven past, not seen → repaired
verify_repairfiled package → verified or escalated
Result6 approved → 2 verified, 1 escalated, 3 open; 8/8 verdicts correct
next survey pass feeds perception again (closed loop)
Evidence that OpenCV 5 output changes the decision (run A/B, traces in eval/results/agent/ablation-*.json): same defect, same prompt, same model at temperature 0, each run in its own rolled-back database transaction; only the measured area differs.
